# Workspace Memory

## Known Roots

- `L:\Code`: default allowed workspace root.
- `L:\Code\Mastra-workspace\OmniAgent`: OmniAgent project root.
- `L:\Code\mastra`: local Mastra framework repository.
- `L:\Code\test-mastra`: earlier local Mastra test agent.
- `L:\Code\recursearch`: downloaded recursearch source archive.

## Environment

- Shell: PowerShell.
- Node.js: 22.x is available.
- Claude Code CLI: available as `claude`.
